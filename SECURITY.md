# Security Policy

## Supported versions

MuseInbox is an early-stage project. Security fixes are applied to the latest
commit on the default branch; older commits and forks are not maintained by this
repository.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include
secrets, access tokens, personal data, or reproducible exploit details in public.

If GitHub's **Security > Report a vulnerability** option is enabled for this
repository, use it to send a private report. Otherwise, contact the V12 Labs
maintainers privately through the contact method published on the
`v12labs-engineering` GitHub organization profile and ask for a secure reporting
channel.

Include the affected revision, impact, reproduction steps, and any suggested
mitigation. Remove or redact credentials and personal data. Maintainers should
acknowledge the report and coordinate disclosure after assessing the issue; no
specific response timeline is promised at this stage.
